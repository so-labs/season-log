# Season Log

漫画・アニメ・小説・映画・ゲームなど、ジャンルを問わないコンテンツの進捗記録アプリ（個人向けWebアプリ）。

「どこまで進めたか」と「最新まで追いついているか」「新しい続きが出ていないか最後に確認した日」を、作品ごとに記録します。

## ✨ 1. 主な機能

- **📚 カード型の作品一覧**: タイトル・進捗・残りをひと目で確認できます。進捗はカード上のボタンで ±1 / ±0.1 ずつ記録でき、小数第1位まで対応しています。
- **🗓 2種類の日付管理**: 最終チェック日（新しい続きが出ているか確認した日）と最終進捗日（実際に進めた日）を分けて記録します。進捗や最大の変更に連動した自動更新つきです。
- **🔍 探しやすい絞り込み**: 検索・カテゴリ絞り込み・フラグ別フィルタ（お気に入り / 完結 / アダルト / 非表示）・並び替え・ビュー（要チェック / 残りあり / 追いつき / 完了）に対応しています。
- **↩️ 元に戻せる安心設計**: 進捗変更や削除は即時反映され、直後8秒間は「元に戻す」で巻き戻せます。

## 🌟 2. 特徴

- **🎨 ライト／ダークテーマ対応**: ブランドカラーはティール。設定で「ライト / システム（OS連動）/ ダーク」を切り替えられます。
- **💾 データはブラウザに保存**: アカウント登録なし、サーバーへの送信なし（IndexedDBに保存）。
- **📦 いつでも持ち出せるデータ形式**: バックアップ / 引き継ぎは CSV / JSON のエクスポート・インポートでいつでも可能。データ形式が開かれているので、Excelに戻すこともできます。
- **📱 スマホでもそのまま**: 横スクロールのないレイアウトで、スマートフォン幅でも使えます。

## 📊 3. データ形式

- CSV: 13列（ID, タイトル, カテゴリ, 進捗単位, 進捗, 最大, お気に入り, 完結, アダルト, 非表示, 最終チェック日, 最終進捗日, メモ）、UTF-8 BOM付き、フラグは 0/1
- JSON: `schemaVersion: 2` のバックアップ形式
- 進捗は小数第1位まで対応（内部では10倍整数で保持）。作品の同一性はIDで判定し、同名タイトルも登録できます

## ⚙️ 4. 開発情報

### 1) 開発

アプリ本体は `app/` ディレクトリにあります（リポジトリ直下では実行できません）。

```sh
cd app
npm install
npm run dev
```

ビルド確認は `npm run build`（型チェック込み）です。

### 2) 使い方

ブラウザで開いて、右上の「＋ 新規登録」から作品を登録します。取り込み・書き出し・テーマ切り替えは、右上の設定（歯車）ボタンから開く設定画面にまとめています。
